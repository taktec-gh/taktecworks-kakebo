# 家計簿アプリ 機能一覧

## このアプリの目的

個人用の家計簿アプリ。目的は「記録」そのものではなく、次の2つの問いに毎月答えられること。

1. **今月、予算内で生活できているか？**
2. **無駄使いはないか？**

この2点が全機能の判断基準。「記録できる」だけで終わるアプリにはしない。

## 前提

| 項目 | 決定 |
|---|---|
| 利用環境 | スマホでも入力する（外出先で買った直後に記録） |
| 入力方法 | 手入力 + レシート撮影OCR |
| 開発方針 | MVPを最短で作って使い始め、そこから足していく |

---

## Phase 1 — MVP（これだけで毎日使える）

### 1. 支出の記録（手入力）

- 日付 / 金額 / カテゴリ / **払い出し先** / メモ
- **浪費フラグ**（必要・浪費・投資 の3択）… 無駄使い検出の中核
- 入力画面はスマホ前提。金額テンキー → カテゴリ選択 → 払い出し先選択 → 保存
- 直近使ったカテゴリ・払い出し先・店名をサジェスト（2回目以降の入力を数タップに）
- 払い出し先はデフォルト値を持たせ、通常は選び直さなくてよいようにする
- 編集・削除

### 2. カテゴリ管理

- 初期カテゴリをプリセット（食費 / 日用品 / 外食 / 交通 / 光熱費 / 通信 / 家賃 / 趣味 / 交際 / 医療 / その他）
- 追加・リネーム・並べ替え・非表示
- カテゴリごとに「固定費 / 変動費」属性を持たせる

### 3. 払い出し先と月次予算

支出を「どこから出したか」で管理する。予算はこの払い出し先単位で持つ。

**払い出し先のタイプは3種類**

1. **現金**
2. **クレジットカード**
3. **銀行引き落とし**

**ユーザーが自分の事情に合わせて任意の数だけ登録できる。** クレジットカードは持っている金種（カード）の数だけ、銀行引き落としは口座の数だけ、あらかじめ追加設定しておける。

- 例: 「現金（財布）」/「Aカード」「Bカード」/「A銀行 引き落とし」「B銀行 引き落とし」

**その他**

- 払い出し先ごとに月次予算を設定できる（例: 現金 ¥40,000 / Aカード ¥50,000 / A銀行 引き落とし ¥95,000）
- 払い出し先の追加・リネーム・並べ替え・無効化（使わなくなったカードは非表示に）
- 収入は「今月使える原資」として登録（家計簿としての収支管理はしない）

### 4. ダッシュボード（＝アプリのトップ画面）

- **残り使える金額**を最上部に大きく表示（全払い出し先の合計）
- **ペース判定**: 「今日時点の理想消化額 vs 実績」で 予算内 / 要注意 / 超過 を色分け
- 月末着地見込み（現在のペースが続いた場合の予測額）
- **払い出し先別 予算バー**（消化率順に並べる＝一番危ない払い出し先が一番上）
- カテゴリ別 予算バー（カテゴリ予算を設定している場合のみ）
- 浪費タグの今月合計額（「今月の無駄使い: ¥X」）

### 5. 支出一覧

- 月切り替え、カテゴリ・払い出し先・浪費タグでの絞り込み、金額順ソート
- 高額順で見ると無駄使いが即座に目に入る

---

## Phase 2 — 無駄使いの発見（分析）

### 6. カテゴリ別の比較

- 前月比 / 過去3ヶ月平均比
- 増えたカテゴリを差額の大きい順に提示（「食費が先月より+¥12,000」）

### 7. 固定費 / 変動費の分解

- 固定費合計・変動費合計と、その推移
- 固定費が上がっている＝見直しの対象

---

## Phase 3 — レシート撮影OCR

### 8. レシート画像からの自動入力

- スマホカメラで撮影 → 日付・店名・合計金額・カテゴリ候補を自動抽出
- 抽出結果は必ず**確認画面**を挟んで手修正可能にする（OCRは100%にならない前提の設計）
- 払い出し先は自動判定せず、確認画面でユーザーが選ぶ（レシートから支払手段を確実に読み取るのは困難なため）
- レシート画像を支出レコードに添付保存

> **Phase 3 は着手時に再検討する。** 使用するOCR技術と、レシート画像の保存先（DBに入れると無料枠を圧迫する）が未決。詳細は [tech-stack.md](./tech-stack.md) の「未決事項」を参照。

## 設計判断

機能一覧だけでは決まらない、仕様上の判断を記録しておく。

### 予算の持ち方 — 払い出し先が主軸

予算軸を2つ持つと合計が食い違って二重管理になるため、主従を決める。

- **払い出し先の予算が主軸。** その合計が今月の総予算になる（総予算を別途手入力はしない）
- **カテゴリ別予算は任意の補助上限。** 設定しなくても成立し、設定した場合は「食費が使いすぎ」を見るための横断ビューとして働く

### クレジットカードの計上タイミング — 支出発生日

カードの実際の引き落としは翌月以降だが、**支出が発生した日で計上する**。「今月いくら使ったか」を知るのが目的であり、引き落とし日ベースにすると当月の使いすぎが1ヶ月遅れて見えるため。締め日・引き落とし日の管理は入れない。

---

## スコープ外（作らないもの）

検討の結果、不要と判断した機能。結果として、入力は手入力とレシートOCRの2経路のみ、分析は比較系のみになる。

- 定期支出の自動計上
- CSVインポート（銀行・クレカ明細）
- 無駄使いレポート（頻度分析・高額Top10）
- 予算アラート
- 資産・口座残高管理（家計簿の範囲が大きく広がるため。収入は「予算の原資」としてのみ扱う）
